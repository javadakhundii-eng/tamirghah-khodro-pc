# RepairShop Pro

نرم‌افزار آفلاین دسکتاپ مدیریت تعمیرگاه خودرو با رابط فارسی RTL، React، Electron و SQLite.

## اجرا و ساخت

```bash
npm install
npm run rebuild:native
npm run dev
# ساخت نصب‌کننده ویندوز (در release/)
npm run dist:win
```

PIN پیش‌فرض: `1234`. پایگاه داده در مسیر داده‌های کاربر Electron با نام `repairshop-pro.sqlite` ساخته می‌شود.

## منطق مالی و موجودی
- ثبت دستور کار همراه با قطعه، موجودی قطعه را کم و در Inventory Card (جدول تراکنش اقلام دستور کار) ثبت می‌کند.
- پرداخت نقدی دستور کار، تراکنش صندوق و سند بستانکار مشتری می‌سازد.
- مانده مشتری از مجموع دفترکل، نه یک ستون ذخیره‌شده، محاسبه می‌شود.
- تمام جداول عملیاتی موردنیاز هنگام اجرای اول ایجاد و داده نمونه فارسی درج می‌شود.
